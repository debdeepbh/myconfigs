# h-m-m for mindmap

Terminal-based tree generator for primarily organizing thoughts.

## Installation

```
sudo apt install php8.3 php-mbstring

```

then use their installation script

```
wget -q -O - 'https://raw.githubusercontent.com/nadrad/h-m-m/main/install.sh' | sh
```

## Usage

- Mostly vim-based navigation
- Ctrl-H to toggle hidden view
- Does not have a way to remove ranking, but you can manually delete it from the file.
- `v` and `b` to expand and collapse
- `s` and `S` to save
- See docs for more keys
